# Security IP Checker

## Project Overview
Security IP Checker is a Python-based cybersecurity project designed to validate, classify, and analyze IP address records.

## Planned Features
- IP address validation
- IPv4 and IPv6 classification
- Invalid IP format detection
- Duplicate IP detection
- Flagged IP records
- Security analysis reports

## Technologies
- Python 3.12
- Git
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Project Status
Currently in development.
