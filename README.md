Security IP Checker

Project Overview

Security IP Checker is a Python-based cybersecurity application that validates, classifies, tracks, and analyzes IP address records through a web-based dashboard and command-line interface.

Features

- IP address validation
- IPv4 and IPv6 classification
- Invalid IP format detection
- Duplicate IP detection
- Flagged IP record management
- SQLite database integration
- IP check history tracking
- Dashboard statistics
- Search and filter functionality
- IP records reporting
- CSV and JSON data handling

Technologies

- Python 3.12
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Git and GitHub

Project Structure

- "app.py" — Flask web application
- "main.py" — Command-line interface
- "ip_checker/" — Core application modules
- "templates/" — HTML templates
- "static/" — CSS and JavaScript files
- "tests/" — Automated tests
